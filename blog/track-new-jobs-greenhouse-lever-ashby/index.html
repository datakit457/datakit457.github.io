Track new job postings at a list of companies (Greenhouse, Lever, Ashby)

Disclosure: I'm the author of the Actor mentioned below (datakit/ats-jobs-feed). The APIs are public and you can do this yourself.

Many startups host careers pages on Greenhouse, Lever or Ashby, and all three expose a public JSON job-board endpoint. Checking 50 careers pages by hand is tedious; diffing the JSON is easy.

Do it yourself (Greenhouse)

import requests, json, pathlib
seen_f = pathlib.Path("seen.json")
seen = set(json.loads(seen_f.read_text())) if seen_f.exists() else set()
jobs = []
for board in ["stripe", "airbnb"]:
    r = requests.get(f"https://boards-api.greenhouse.io/v1/boards/{board}/jobs").json()
    jobs += [(f"gh:{board}:{j['id']}", j["title"], j["location"]["name"], j["absolute_url"]) for j in r["jobs"]]
for id_, title, loc, url in jobs:
    if id_ not in seen: print(title, "|", loc, "|", url)
seen_f.write_text(json.dumps(sorted(seen | {j[0] for j in jobs})))

Lever: https://api.lever.co/v0/postings/<company>?mode=json. Ashby: https://api.ashbyhq.com/posting-api/job-board/<company>. Each has different field names, which is the annoying part.
