Get Philippines job listings as JSON (Kalibrr) and alert on new ones

Disclosure: I'm the author of the Actor mentioned below (datakit/kalibrr-jobs-feed). The endpoint in the first example is public and you can use it yourself.

Kalibrr is a major job board for the Philippines and Indonesia. Its public search endpoint returns clean JSON without a login, which makes it easy to feed a spreadsheet, a Slack channel or a recruiter dashboard.

Do it yourself

import requests
r = requests.get(
    "https://www.kalibrr.com/kjs/job_board/search",
    params={"limit": 20, "offset": 0, "country": "Philippines", "text": "python"},
    headers={"User-Agent": "Mozilla/5.0"},
).json()
for j in r["jobs"]:
    print(j["name"], "|", j["company_name"], "|", j["function"], "|", j["tenure"])

I ran this on 2026-11-08: the search for "python" returned 38 matches, each with title, company, job function, tenure (full time etc.), work-from-home and hybrid flags, and an HTML description. Page through results with offset. Be polite: add a delay between pages and cache what you fetch.

What the raw endpoint does not do: remember which jobs you already saw, filter by city, or give you plain-text descriptions. You would write that yourself (store job ids in a file and diff on each run).

Or use the Actor

datakit/kalibrr-jobs-feed does the paging, filters by keywords, cities, job function and work-from-home, strips the HTML, and in newSinceLastRun mode returns only jobs not seen in earlier runs with the same State name. Schedule it daily and send the output wherever you like.

curl -X POST "https://api.apify.com/v2/acts/datakit~kalibrr-jobs-feed/run-sync-get-dataset-items?token=YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"mode":"newSinceLastRun","keywords":["python"],"cities":["Makati"],"stateKey":"python-makati"}'

Use a different stateKey per filter set so each feed keeps its own "already seen" list.

Limits
