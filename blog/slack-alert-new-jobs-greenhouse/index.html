Get a Slack alert when a company posts a new job (Greenhouse, Python)

Disclosure: I'm the author of the Actor mentioned at the end (datakit/ats-jobs-feed). The script below works without it.

If you are waiting for a specific company to open a role, a 20-line script plus a Slack incoming webhook does the job. Greenhouse publishes every board as JSON at https://boards-api.greenhouse.io/v1/boards/<company>/jobs, no login needed.

The script

import requests, json, pathlib

WEBHOOK = "https://hooks.slack.com/services/XXX/YYY/ZZZ"   # your Slack incoming webhook
BOARD, KEYWORD = "stripe", "engineer"
seen_f = pathlib.Path("seen.json")
seen = set(json.loads(seen_f.read_text())) if seen_f.exists() else set()

jobs = requests.get(f"https://boards-api.greenhouse.io/v1/boards/{BOARD}/jobs", timeout=30).json()["jobs"]
new = [j for j in jobs if str(j["id"]) not in seen and KEYWORD in j["title"].lower()]
if seen and new:   # skip the alert on the very first run, which would list every open job
    text = "\n".join(f"{j['title']} ({j['location']['name']}) {j['absolute_url']}" for j in new[:10])
    requests.post(WEBHOOK, json={"text": text}, timeout=30)
seen_f.write_text(json.dumps([str(j["id"]) for j in jobs]))

I ran the fetch and diff part against the Stripe board: the first run found 187 matching jobs, the second found 0. Run it from cron every few hours (0 /6 python3 /path/alert.py).

Caveats

  • The slug is the one in the company's careers URL (boards.greenhouse.io/<slug>). Not every company uses Greenhouse; Lever and Ashby have similar endpoints with different field names.
  • Storing only current ids means a job that is removed and re-posted alerts again. That is usually what you want.
