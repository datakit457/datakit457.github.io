Export all open jobs from an Ashby careers page to CSV (Python)

Disclosure: I'm the author of the Actor mentioned at the end (datakit/ats-jobs-feed). The script below works without it.

Companies that hire through Ashby publish their open postings as JSON at https://api.ashbyhq.com/posting-api/job-board/<slug>, no login or key needed. The slug is the one in the jobs URL (jobs.ashbyhq.com/<slug>).

The script

import csv, requests

SLUG, KEYWORD = "ramp", "engineer"
data = requests.get(f"https://api.ashbyhq.com/posting-api/job-board/{SLUG}", timeout=30).json()
rows = [j for j in data["jobs"] if j.get("isListed", True) and KEYWORD in j["title"].lower()]

with open("jobs.csv", "w", newline="") as f:
    w = csv.writer(f)
    w.writerow(["title", "location", "department", "workplace", "remote", "published", "url"])
    for j in rows:
        w.writerow([j["title"], j.get("location"), j.get("department"), j.get("workplaceType"),
                    j.get("isRemote"), j.get("publishedAt"), j["jobUrl"]])

I ran this against the Ramp board: 169 open postings, 36 with "engineer" in the title; the first row was a hybrid New York role.

Caveats

  • Titles can have stray whitespace; .strip() them if you sort or deduplicate.
  • publishedAt is an ISO timestamp, handy for "posted in the last 7 days" filters.
  • Each job also carries descriptionPlain if you want to search the full text.
