Export all open jobs from a Lever careers page to CSV (Python)

Disclosure: I'm the author of the Actor mentioned at the end (datakit/ats-jobs-feed). The script below works without it.

Companies that hire through Lever expose their open postings as JSON at https://api.lever.co/v0/postings/<company>?mode=json, no login or key needed. The slug is the one in the company's jobs URL (jobs.lever.co/<slug>).

The script

import csv, requests

SLUG, KEYWORD = "palantir", "engineer"
jobs = requests.get(f"https://api.lever.co/v0/postings/{SLUG}", params={"mode": "json"}, timeout=30).json()

with open("jobs.csv", "w", newline="") as f:
    w = csv.writer(f)
    w.writerow(["title", "location", "workplace", "team", "url"])
    for j in jobs:
        if KEYWORD in j["text"].lower():
            c = j["categories"]
            w.writerow([j["text"], c.get("location"), j.get("workplaceType"), c.get("team"), j["hostedUrl"]])

I ran this against the Palantir board: 305 open postings, 185 with "engineer" in the title; the first row was a hybrid London role.

Caveats

  • Fields differ by company (team or location can be missing), hence .get().
  • createdAt is a millisecond timestamp, useful for "posted in the last 7 days" filters.
  • A wrong slug returns an error body rather than a list; check the status code if you loop over many companies.
