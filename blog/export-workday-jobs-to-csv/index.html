Export open jobs from a Workday careers site to CSV (Python)

Disclosure: I'm the author of the Actor mentioned at the end (datakit/ats-jobs-feed). The script below works without it.

Many large employers run their careers site on Workday, at URLs like https://<company>.wd5.myworkdayjobs.com/<site>. The page itself is a JavaScript app, but it loads its job list from a public JSON endpoint you can call directly: POST https://<host>/wday/cxs/<company>/<site>/jobs. No login or key is needed.

The script

import csv, requests

URL = "https://nvidia.wd5.myworkdayjobs.com/NVIDIAExternalCareerSite"   # the company's careers URL
KEYWORD = "engineer"

host, site = URL.split("/")[2], URL.rstrip("/").split("/")[-1]
tenant = host.split(".")[0]
api = f"https://{host}/wday/cxs/{tenant}/{site}/jobs"

jobs, offset, total = [], 0, None
while True:
    body = {"appliedFacets": {}, "limit": 20, "offset": offset, "searchText": KEYWORD}
    page = requests.post(api, json=body, timeout=30).json()
    if total is None:
        total = page.get("total", 0)   # only the first page carries the real total
    jobs += [j for j in page.get("jobPostings", []) if j.get("title")]
    offset += 20
    if offset >= total or not page.get("jobPostings"):
        break

with open("jobs.csv", "w", newline="") as f:
    w = csv.writer(f)
    w.writerow(["title", "locations", "posted", "req_id", "url"])
    for j in jobs:
        w.writerow([j["title"], j.get("locationsText"), j.get("postedOn"),
                    (j.get("bulletFields") or [""])[0], f"https://{host}/{site}{j['externalPath']}"])
print(len(jobs), "jobs")

I ran this against NVIDIA's careers site with the keyword "engineer": 1,999 postings written to jobs.csv. The first row was "Director, Engineering – Software Engineering", 2 locations, posted 30+ days ago.

Caveats

  • Only the first page has the real total. Later pages return total: 0, so read it once, as above. If you loop on each page's total, you stop after 20 jobs.
  • 2,000 is the ceiling. Workday never reports more than 2,000 results for one query. If you hit it, narrow the search (searchText) or run several keywords.
  • limit is 20 at most. Larger values are rejected.
  • Dates are relative. postedOn is text like "Posted 4 Days Ago" or "Posted 30+ Days Ago", not a timestamp. Store the date you first saw each job if you need history.
  • Locations can be a count. Jobs in several places show "2 Locations". For the full list and the description, call GET https://<host>/wday/cxs/<company>/<site><externalPath> for each job and read jobPostingInfo.
  • Some list entries have no title. Skip them.
  • Check the site's robots.txt first (https://<host>/robots.txt); career sites usually allow the main site path.
