Export UK food hygiene ratings to CSV with Python (FSA open API)

Disclosure: I'm the author of the Actor mentioned at the end (datakit/uk-new-food-business-leads). The API used below is the Food Standards Agency's open API and works without it.

Want every restaurant or café in one UK council area in a spreadsheet? The FSA's Food Hygiene Rating Scheme (FHRS) API is free, needs no key, and is published under the Open Government Licence v3.

import csv, requests
H = {"x-api-version": "2", "accept": "application/json"}
rows, page = [], 1
while True:
    r = requests.get("https://api.ratings.food.gov.uk/Establishments", headers=H, timeout=30, params={
        "localAuthorityId": 401,   # Middlesbrough; list IDs via /Authorities/basic
        "businessTypeId": 1,       # 1 = Restaurant/Cafe/Canteen; list via /BusinessTypes
        "pageSize": 100, "pageNumber": page}).json()
    rows += r["establishments"]
    if page >= r["meta"]["totalPages"]:
        break
    page += 1
with open("ratings.csv", "w", newline="") as f:
    w = csv.writer(f)
    w.writerow(["name", "postcode", "rating", "inspected", "type"])
    for e in rows:
        w.writerow([e["BusinessName"], e["PostCode"], e["RatingValue"], (e["RatingDate"] or "")[:10], e["BusinessType"]])
print(len(rows), "rows")

Run on 2026-11-09 for Middlesbrough, this produced 243 restaurants/cafés over 3 pages. Open ratings.csv in Excel or import it into Google Sheets.

Notes

  • RatingValue can be text such as "AwaitingInspection" or "Exempt", not just 0-5.
  • Be polite: pause between pages when looping over many authorities.
  • The data has no contact details; handle any outreach under PECR/GDPR.
