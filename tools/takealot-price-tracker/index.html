Takealot price drop tracker: only the products whose price changed

An Apify Actor that searches Takealot for your keywords, remembers each product's price and stock, and outputs only the changes on later runs.

Who it is for

  • Resellers and dropshippers watching supplier or competitor prices
  • Deal sites and Telegram/WhatsApp bargain channels
  • Analysts tracking South African electronics and appliance prices

How it works

Enter keywords such as airfryer or rtx 4060. The first run records a baseline; later runs emit rows with change = price_drop, price_rise, new or back_in_stock. A minimum price-change percentage filters noise.

Example row

{"title": "Russell Hobbs Digital 9L Air Fryer", "change": "price_drop", "priceZAR": 1199, "previousPriceZAR": 1499, "changePercent": -20}

Data and limits

Uses Takealot's public search endpoint; no login, no personal data. Prices in ZAR, lowest seller price. Not affiliated with Takealot.

FAQ

Which changes are reported?

price_drop, price_rise, new listing and back_in_stock, on runs after the first baseline.

Which currency and price?

South African rand, lowest seller price shown by Takealot.

Can I ignore tiny changes?

Yes, set a minimum price-change percentage.

Is it affiliated with Takealot?

No, it is an independent tool using the public search endpoint.
