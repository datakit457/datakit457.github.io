EU public tenders from TED by CPV code, country and keyword, new notices only

An Apify Actor that queries the official TED Search API (EU Publications Office open data) and returns calls for tenders, contract awards or prior information notices matching your CPV codes, buyer countries and keywords. In newOnly mode it outputs only notices it has not shown you before, so a daily schedule becomes a tender alert.

Who it is for

  • Companies that bid on public contracts: IT, construction, consulting, facility services, medical supplies
  • Bid managers and tender consultants watching several sectors or countries
  • Market researchers who want a CSV of who buys what, where

Input

cpvCodes (parent codes include children: 72000000 = IT services, 45000000 = construction), countries (ISO alpha-3, e.g. DEU, IRL, POL), keywords, noticeKind (competition, result, planning, all), daysBack, maxResults, mode and stateKey.

Example row

{"noticeId": "768285-2026", "title": "Beschaffung eines zentralen Social-Media Content Management Tools", "buyerName": "Landesamt für Zentrale Polizeiliche Dienste NRW", "buyerCountry": "DEU", "deadline": "2026-12-07", "cpvCodes": ["72260000"], "procedureType": "open"}

Data and limits

Official TED API, no login, no scraping of web pages, no personal data. TED covers above-threshold contracts in the EU/EEA (about 2,000 notices per working day); small national-only tenders are not included. Estimated value appears only when the buyer published one.

FAQ

Is TED data free to reuse?

Yes. TED is EU open data from the Publications Office; this Actor uses its public search API.

What is a CPV code?

The EU Common Procurement Vocabulary: 8-digit sector codes. Parent codes match all children, so 72000000 returns every IT-services tender.

How do I get daily alerts?

Save a task with mode newOnly and a fixed stateKey, schedule it daily, and connect Slack, email or Google Sheets.

Which countries are covered?

Every notice published in TED: EU member states, EEA and others that publish there.
